## 3. 日历页面

### 3.1 月视图

- 显示当前月份的日历网格（7列 × 5-6行）
- 每个格子显示日期数字和当天的事件
- 跨天事件显示为连续横条，跨越多个日期格子
- 当天日期高亮显示

### 3.2 年视图

- 显示12个月的缩略日历
- 有事件的日期有标记
- 点击某月可切换到该月视图

### 3.3 添加事件

1. 点击某天日期格子
2. 在弹窗中填写：标题、开始日期、结束日期、颜色
3. 点击"保存"

### 3.4 编辑/删除事件

1. 点击已有事件
2. 在弹窗中修改信息或点击"删除"

### 3.5 保存为图片

点击"保存为图片"按钮，将当前日历视图导出为 PNG 图片。

### 3.6 导出 Excel

点击"导出"按钮，将日历事件导出为 Excel 文件。

## 4. 任务页面

### 4.1 任务列表

- 显示所有任务，按创建时间倒序
- 每个任务显示：完成状态、标题、分类标签、优先级
- 点击勾选框标记完成/未完成

### 4.2 任务详情（Markdown）

- 点击任务标题展开详情
- 支持 Markdown 语法：标题、列表、代码块、链接等
- 再次点击折叠

### 4.3 添加任务

1. 点击"新建任务"按钮（或按 `n` 键）
2. 填写：标题、描述（Markdown）、分类、优先级、日期
3. 点击"保存"

### 4.4 编辑/删除任务

- 点击任务右侧"编辑"图标修改
- 点击"删除"图标删除

### 4.5 搜索和筛选

- 搜索框：按标题模糊搜索
- 分类筛选：点击分类标签筛选
- 状态筛选：全部/未完成/已完成

### 4.6 Excel 导入导出

- **导出**：将当前任务导出为 Excel 文件
- **导入**：选择 Excel 文件导入任务
- **模板**：下载 Excel 模板，按格式填写后导入

## 9. 数据加密说明

### 9.1 加密原理

```
你的密码 → PBKDF2派生(10万次迭代) → AES-256密钥 → 加密所有数据
```

### 9.2 数据存储

- 所有数据加密后存储在浏览器 localStorage
- 密码不存储在任何地方，只在登录时存在于内存中
- 关闭页面后密钥消失，数据无法被解密

### 9.3 安全保障

- **传输安全**：GitHub Pages 使用 HTTPS
- **存储安全**：AES-256-GCM 加密
- **密码安全**：SHA-256 哈希比对，不存明文
- **路由安全**：秘密 hash 路由，不知道的人看不到入口

### 9.4 数据备份

- 定期使用 Excel 导出功能备份重要数据
- 换密码前必须导出数据（换密码后数据会重置）

## 10. 常见问题

### Q1: 忘记密码怎么办？

密码无法找回（没有后端、没有邮箱验证）。需要修改 `src/utils/security.js` 中的密码哈希并重新部署。注意换密码后数据会重置。

### Q2: 换了浏览器数据还在吗？

不在。数据存在 localStorage 中，每个浏览器独立。换浏览器后数据为空。

### Q3: 清除浏览器缓存会丢数据吗？

会。清除缓存/网站数据会清除 localStorage，所有数据丢失。建议先导出备份。

### Q4: 多人可以同时使用吗？

可以，但数据不共享。每个人在自己浏览器中独立操作，数据互不影响。

### Q5: 数据有大小限制吗？

localStorage 通常限制 5-10MB。加密后体积会增大，建议大量数据用 Excel 导出。

### Q6: 手机能用吗？

能。页面做了响应式适配，手机浏览器打开同一 URL 即可使用。

### Q7: 为什么直接打开链接是404？

这是安全设计。必须带 `#/s7x9k2m4` 才能进入密码登录页面。

### Q8: 如何修改密码？

1. 计算新密码的 SHA-256 哈希：`echo -n "新密码" | sha256sum`
2. 修改 `src/utils/security.js` 中对应哈希值
3. 重新构建部署
4. 详见 [Git推送手册](./Git推送手册.md)

### Q9: 如何修改秘密路由？

修改 `src/utils/security.js` 中 `SECRET_ROUTE` 的值，重新部署。

### Q10: 如何添加新的任务分类？

在任务页面点击"分类管理"按钮，添加新分类。普通用户和管理员都可以操作。
