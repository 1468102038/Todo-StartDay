## 1. 项目总览

StartDay 是一个基于 React 18 + Vite 5 的前端单页应用，功能是日历 + 任务管理 + 竞赛筛选 + 公告 + 资料共享 + 建议反馈。部署在 GitHub Pages 上，采用多层安全伪装保护隐私。

**核心特点：**
- 纯前端，无后端服务器
- 数据加密存储在浏览器 localStorage
- 多角色密码体系（普通用户/管理员/超级管理员）
- Excel 导入导出（使用 SheetJS）
- Markdown 渲染（使用 marked）
- 自定义日历日期选择器

## 3. 入口文件链路

应用启动的完整链路：

```
index.html
  └── 加载 /src/main.jsx
        └── 渲染 <SecretRouter> 包裹 <App />
              ├── hash 路由不匹配 → <NotFoundPage />（404伪装）
              └── hash 路由匹配 (#/s7x9k2m4)
                    └── <PasswordGate> 包裹 <App />
                          ├── 未登录 → 密码输入界面
                          └── 已登录 → <App />（主应用）
                                ├── useStore() 加载加密数据
                                └── 渲染当前页面（日历/任务/竞赛/...）
```

## 4. 安全架构详解

### 4.1 四层安全模型

```
┌─────────────────────────────────────────────┐
│  第1层：404 伪装页面（NotFoundPage.jsx）      │
│  直接访问 → 显示 GitHub 风格 404 页面          │
├─────────────────────────────────────────────┤
│  第2层：秘密路由（SecretRouter.jsx）           │
│  URL 必须包含 #/s7x9k2m4 才能进入密码门        │
├─────────────────────────────────────────────┤
│  第3层：密码验证（PasswordGate.jsx）           │
│  SHA-256 哈希比对，不存储明文密码              │
├─────────────────────────────────────────────┤
│  第4层：数据加密（crypto.js + storage.js）     │
│  AES-256-GCM 加密 localStorage 中的所有数据    │
└─────────────────────────────────────────────┘
```

### 4.2 密码验证流程

```
用户输入密码 → sha256(密码) → 对比 security.js 中的哈希值
  ├── 匹配超级管理员哈希 → 角色 = 'superadmin'
  ├── 匹配管理员哈希 → 角色 = 'admin'
  ├── 匹配普通用户哈希 → 角色 = 'user'
  └── 都不匹配 → 提示"密码错误"
验证通过后：
  1. sessionStorage 存储认证状态（关闭标签页即清除）
  2. CustomEvent 把密码传给加密层（不持久化）
  3. 加密层用密码派生 AES 密钥
  4. 通知 useStore 加载数据
```

### 4.3 加密流程

```
密码 → PBKDF2(100000次, SHA-256) → AES-256-GCM密钥 → 加密localStorage
加密：JSON.stringify(数据) → encrypt() → base64密文 → localStorage
解密：localStorage → base64密文 → decrypt() → JSON.parse → 数据
```

**关键点：**
- 密码只在登录时通过 CustomEvent 传递，不存入任何持久存储
- 加密密钥只存在内存变量中
- 关闭页面后密钥消失，数据无法解密
- 换密码 = 换密钥 = 旧数据无法解密

## 5. 数据流与状态管理

### 5.1 useStore Hook — 全局数据中心

管理所有状态：todos、contests、categories、priorities、contestCategories、announcements、resources、resourceCategories、suggestions

### 5.2 数据加载流程

```
App 挂载 → useStore() 初始化 → 等待加密密钥就绪
→ 并行加载所有数据 → 解密 → JSON.parse → 设置 state → dataReady=true → 渲染
```

### 5.3 数据保存流程

```
用户操作 → setTodos() → useEffect 检测变化 → debouncedSave(300ms防抖)
→ saveDataSecure() → JSON.stringify → encrypt() → localStorage
```

| 技术 | 版本 | 用途 |

## 8. 常见修改指南

### 8.1 修改密码

1. 计算新密码的 SHA-256 哈希：
   ```bash
   echo -n "新密码" | sha256sum | awk '{print $1}'
   ```
2. 打开 `src/utils/security.js`
3. 替换对应的哈希值：
   - `DEFAULT_PASSWORD_HASH` — 普通用户密码
   - `DEFAULT_SUPERADMIN_HASH` — 超级管理员密码
   - `DEFAULT_ADMIN_HASH` — 管理员密码
4. 更新注释中的密码明文（方便记忆）
5. 重新构建部署

> ⚠️ 换密码后旧数据无法解密，会重置为空。

### 8.2 修改秘密路由路径

1. 打开 `src/utils/security.js`
2. 修改 `SECRET_ROUTE` 的值（如改为 `mySecret123`）
3. 访问地址变为 `#/mySecret123`
4. 重新构建部署

### 8.3 添加新页面

1. 在 `src/pages/` 下创建新页面组件
2. 在 `src/App.jsx` 中注册导航项和路由
3. 如需数据，在 `src/hooks/useStore.js` 添加 state 和 CRUD 方法
4. 重新构建部署

### 8.4 修改默认分类

打开 `src/hooks/useStore.js`，修改对应的 DEFAULT_CATEGORIES 等常量。注意只影响新用户。

### 8.5 修改仓库名 / 部署路径

修改 `vite.config.js` 中的 `base` 为新路径，重新构建部署。

### 8.6 修改主题颜色

打开 `src/styles/global.css`，修改对应主题的 CSS 变量值。

### 8.7 添加新依赖

```bash
npm install 包名
```

然后在代码中 import 使用。构建时会自动打包。
